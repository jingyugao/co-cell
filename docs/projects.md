# 项目与会话

项目是工作区和 E2B 沙箱的所有者。创建项目时可以填写飞书需求详情 URL，由宿主机已登录的 Meegle CLI 读取需求名称作为项目名，无需手工输入；未绑定需求时仍需填写项目名。

名称读取流程为 `url decode` → `auth status` → `project search` → `workitem get`。仅接受具体工作项详情链接，并核对登录站点、空间和工作项 ID；失败时不保存半成品项目，页面保留输入并显示错误。每条 CLI 命令最多等待 15 秒，使用独立参数调用，不通过 shell 执行链接，不向页面输出凭据或 CLI 原始错误。项目名最长 100 字符，超长需求标题截短后保存，原始需求链接保持完整。

绑定需求的项目在新会话顶部展示“阅读需求并产出技术方案”快捷卡片，与其他示例任务卡片并列。点击后将提示词填入输入框：读取完整需求及相关材料，结合共享项目/模块文档和实际代码，输出目标范围、涉及模块、流程与改动、接口和数据设计、风险、验证与待确认事项。用户可修改后发送，创建项目不会自动启动 Agent。草稿按项目或会话在当前页面内保存，切换和会话事件不会覆盖已修改或主动清空的内容；刷新页面不保留手工草稿。已有对话不插入默认任务。

需求名称只在创建时读取，不持续同步；后续编辑名称或需求链接不自动改名。需求正文由 Agent 在任务执行时读取，不作为项目记录缓存。

项目内多个会话共用一个沙箱、工作目录和已安装工具，各自保存 Codex thread 与消息历史。首次执行项目任务才创建沙箱，创建项目或会话本身不会启动沙箱。

## 页面与执行

- 会话地址为 `/sessions/<会话ID>`，项目的新会话入口为 `/projects/<项目ID>`。刷新、复制链接以及浏览器前进后退都会按路径定位到对应项目或会话，已归档项目同样适用。显式路径优先于本机上次打开的记录；会话或项目不存在时显示错误，不自动打开其他会话。
- 管理页面继续使用 `#projects`、`#sandboxes` 等入口，可附在当前会话路径后；返回对话保留原会话。旧的 `/` 入口仍可恢复本机上次选择，并替换为对应路径。首次创建会话后，用会话路径替换项目的新会话路径。
- `/#projects`：创建、编辑、进入、归档或取消归档项目。进行中与已归档列表分开展示，已归档列表按归档时间倒序排列。创建项目需要已配置的 E2B 执行环境。
- 进入项目后，“新建会话”开始独立对话；历史仅展示当前项目的会话，本机历史不提供页面入口。
- 侧栏项目切换器直接展示进行中项目，已归档分组默认折叠，展开后才能选择；重新打开切换器时归档分组恢复折叠，当前已选中的归档项目名称仍正常显示。
- 执行环境和工作目录由项目固定；模型、思考强度、网页搜索按会话保存。
- 新会话默认 `gpt-6-astra`，输入框旁可直接选择 `gpt-6-astra` 或 `gpt-5.6-sol`；已有会话保留原模型，切换后保存到会话设置，执行中禁止切换。设置弹窗提供相同的模型选项。
- E2B 内统一使用沙箱内完全访问和命令联网；Agent 的工作区约定通过 `AGENTS.md` 提供。
- 同项目多个会话可共享沙箱和工作区并行执行，各自保留独立 Codex thread；文件、Git 状态和服务端口冲突由使用者协调。同一会话仍一次执行一个任务。

停止任务只终止该会话的进程，保留项目文件，其他会话继续执行。后台每分钟巡检一次，项目超过 1 小时无活动且没有任务或读取操作时才暂停；最后活动时间持久化，服务重启后继续巡检。删除会话仅删除其网页历史和附件，最后一个会话删除后项目沙箱仍存在。归档仅记录 `archivedAt` 并改变展示分组，不停止任务、不删除会话、文件或沙箱；归档项目仍可继续对话、创建会话和编辑。开始时间为项目创建时间，结束时间为归档时间；取消归档清空归档时间，移回进行中列表。归档不改变上述空闲暂停规则。页面不再提供删除项目入口，原有 DELETE API 仍保留。

关闭或刷新页面不停止任务。重启 Web 服务会中断活动任务，之后可以继续原 thread 和工作区，但不会自动重放被中断的 turn。沙箱已被外部删除时会明确报错。

## 持久化与兼容

默认项目目录为 `.codex-web/projects/`，会话保存在 `.codex-web/` 下；可通过 `CODEX_WEB_DATA_DIR` 改变这一根目录。`project.sandbox` 是映射的权威来源，`session.projectId` 表示归属，`session.sandbox` 为兼容快照。

启动时，未归属项目的旧 E2B 会话会迁移为项目，保留原有沙箱、thread 和目录。项目先持久化，再写入会话归属；重启可重复执行迁移而不创建重复项目。已有项目的沙箱映射优先于会话旧快照。

本机历史不会被这项迁移删除，但不在页面历史列表展示；启用 E2B 时本机旧会话不能继续执行。新 E2B 会话也不能导入宿主机的 Codex thread。

## API

| 方法 | 路径 | 含义 |
| --- | --- | --- |
| GET | `/api/projects` | 项目列表、会话数和活动会话 |
| POST | `/api/projects` | 创建项目，`{name?: string, requirementUrl?: string|null}`；绑定需求时自动取名，否则 name 必填 |
| GET | `/api/projects/:id` | 项目详情 |
| PATCH | `/api/projects/:id` | 修改名称、可选需求 URL；`{archived: true}` 归档，`{archived: false}` 取消归档 |
| DELETE | `/api/projects/:id` | 删除项目、全部会话及沙箱 |
| POST | `/api/sessions` | 指定 `projectId` 创建项目会话 |

旧客户端未传 `projectId` 的 E2B 会话请求仍可自动建立项目。创建后的会话不能迁移到另一项目，也不能单独变更执行环境或工作目录。

## 服务链接

E2B 会话回复中的 HTTP/HTTPS 本地服务链接（localhost、127.0.0.1、0.0.0.0、IPv6 loopback）可点击打开，包括仅包含 URL 的行内代码；`0.0.0.0:8000`、`localhost:8000` 这类不带协议的地址默认按 HTTP 处理。点击后通过项目预览接口连接或恢复原沙箱，再跳转到 E2B 端口网关，保留路径、查询参数和页面锚点。服务需监听可从沙箱网关访问的地址，例如 `0.0.0.0:8000`。普通外网链接照常打开，代码块不改写。

当前本机网关使用 `http://<端口>-<沙箱ID>.localhost:13002`，供本机浏览器访问。点击预览入口会更新项目活动时间；随后页面请求直接经过 E2B 网关，不经过聊天后端。
